### 📊 TrendSentiment | Análisis de sentimientos con Python

Proyecto académico enfocado en el procesamiento y análisis de información utilizando Python.

Desarrollé un script que procesa publicaciones sintéticas almacenadas en archivos JSON y realiza una clasificación léxica básica de sentimientos.

**Características:**

- Lectura y procesamiento de información JSON.
- Organización y manipulación de datos mediante Pandas.
- Clasificación de publicaciones utilizando conjuntos de palabras positivas y negativas.
- Visualización de resultados mediante Matplotlib.

**Tecnologías:** Python, Pandas, Matplotlib, JSON y expresiones regulares.

> Proyecto demostrativo con datos sintéticos. No establece conexión con X/Twitter ni utiliza un modelo de inteligencia artificial entrenado.
